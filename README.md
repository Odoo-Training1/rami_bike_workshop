# Bike Workshop Module for Odoo 19

A custom Odoo 19 module designed for managing bike workshop operations, specifically handling bike fleets, types, rental pricing, maintenance dates, and security access.

---

## Overview
Rami's Bike Workshop requires a smooth system to manage rental operations for tourists and locals. This application digitalizes the fleet inventory, allowing authorized staff to manage bikes efficiently through dedicated List and Form views.

---

##  Features
 **Fleet Management:** Track bike name/code, brand, purchase date, and last maintenance date.
**Bike Categories:** Categorize bikes using a Selection field (`Road`, `Mountain`, `City`, `Electric`).
**Financial & Physical Specs:** Record daily rental prices and wheel sizes in inches.
**Database Security & Constraints:** Built-in unique constraints for bike names/codes and strict model access control rights (`ir.model.access.csv`).
* **User-Friendly UI:** Fully integrated List and Form views accessible via a custom application menu.
